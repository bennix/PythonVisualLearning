01 / 定义与调用
def 定义，调用才执行
def 名字(形参): 定义函数，缩进部分是函数体，定义时并不运行。return 把值交还给调用者并结束函数；没有 return 就返回 None。return a, b 返回元组。
函数内部赋值的变量是局部变量，函数外看不到。函数本身也是对象，可以赋值、传递。


02 / 参数形式
定义顺序：普通 → 默认 → *args → 仅关键字 → **kwargs
调用时位置实参按顺序对应，关键字实参 名=值 按名字对应，位置实参必须写在关键字实参前面。exp=2 是默认值，不传就用它。*args 收集多余位置实参成元组，**kwargs 收集多余关键字实参成字典。
单独的 * 后面是仅关键字参数，/ 前面是仅位置参数。调用时 *列表、**字典 可以拆包。默认值不要用列表等可变对象。


03 / lambda 与排序
key 决定按什么比
lambda 参数: 表达式 是只有一个表达式的匿名函数，自动返回表达式的值，常直接写在需要函数的地方。
sorted(数据, key=函数, reverse=False)：先对每个元素调用 key 得到比较值，再按比较值排序，元素本身不变；key 相同时保持原顺序（稳定排序）。key 返回元组可以多条件排序。list.sort() 原地排序并返回 None，sorted() 返回新列表。
