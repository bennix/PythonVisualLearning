Python 函数实验室 · 使用说明
============================

打开方式
  双击 index.html，用浏览器（Chrome / Safari / Edge）打开即可。
  完全离线，无需联网、无需安装任何东西。

页面内容
  一台等距“函数装配台”机器：
  · 前排槽位 = 调用时传入的实参，下方小字标明“位置”或“关键字”
  · 后排槽位 = 函数定义的形参，下方小字是形参名和默认值（如 exp=2）
  · 拾取滑台逐个处理实参，高亮的块就是正在落进形参的那个
  · 右侧托盘：多出来的位置实参 → *args（元组，压着封条表示不可变）
               多出来的关键字实参 → **kwargs（字典）
  · 竖旗落下 = 调用出错（如参数个数不对）
  · 右前方显示屏 = 返回值；排序示例中显示排好序的 key 值
  · 排序示例：前排下方小字是每个元素的 key 值，后排是排好序的结果

四个主题，共 30 个预设示例
  1. 定义与调用（5 个）：def 与 return、没有 return 返回 None、
     return 多个值、函数是对象、局部变量
  2. 参数形式（13 个）：位置参数、关键字参数、默认参数（不传 / 覆盖）、
     *args、**kwargs、仅关键字参数（* 之后，正确与错误调用）、
     仅位置参数（/ 之前）、几种形式组合、缺少参数报错、
     调用时用 ** 拆包、可变默认值的陷阱
  3. 匿名函数 lambda（4 个）：基本写法、多个参数与默认值、
     与 def 等价、配合 map / filter
  4. 排序中的 lambda（8 个）：默认排序（大写在前）、key=len、
     忽略大小写、按元组第 2 项、reverse=True、多条件排序、
     key=abs、sort() 原地排序返回 None

操作
  · 右侧选主题、点示例；“重播”“暂停巡览”按钮
  · 点击图后：← → 切换示例，Home / End 跳到首/尾，空格或回车重播
  · 右上角切换浅色 / 深色模式；无人操作时自动巡览
  · 系统开启“减少动态效果”时，直接显示最终状态，不播放动画
  · 机器上的显示屏空间有限，较长的返回值或错误信息会用 … 截断，
    完整内容始终显示在右侧“代码与结果”面板

说明
  · 所有结果都由真实 Python 3.10.21 预先运行得出，内置在页面中；
    实参落进哪个形参，由 Python 的 inspect.signature().bind() 计算，
    与真实调用规则一致。浏览器并不执行任意 Python 代码。

文件夹结构
  index.html      成品（单文件，所有资源已内联）
  source/         源码
    truth.py        运行全部示例并编排每一步动画，生成 truth.json
    build.mjs       用 Anatomy kit 生成等距 SVG 并打包 index.html
    live.js         交互、绘制与动画
    template.html / style.css
    test.py         独立复核：重新运行示例、重新计算参数绑定和排序
    browser-tests.json / fit-test.js  浏览器交互与文字尺寸测试
  验证/           验证截图（浅色、深色、手机、4 倍细节、线端检查）

重新构建（需要 Node.js 和 Python 3.8 以上）
  cd source
  python3 truth.py
  node build.mjs
  python3 test.py
