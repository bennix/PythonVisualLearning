Python 正则表达式实验室

打开方式
双击本目录 index.html，用 Chrome 打开即可。网页是独立单 HTML，CSS、SVG、JavaScript 和 Python 预计算结果全部内嵌；不需要网络、服务器、安装依赖或 Python 运行时。源码单独保存在 source 中，便于修改重建。

操作
1. 在元字符、基本函数、综合案例三类中选择案例（39 个）。
2. 切换 flags 预设：默认、I、M、S、IM、IS、MS、IMS。第 24 个案例还可对比 search、match、fullmatch。共 328 种预计算组合。
3. 点选正则 token 阅读解释。点选匹配区间，或用上一个/下一个切换匹配。
4. 播放扫描按已计算结果轮播；暂停和重播控制展示。滑台和双夹具按全文码点长度归一化定位，轨道上的小板不是字符槽，不能据其数量推断文本长度。
5. 图形获得键盘焦点后，左右键切换匹配，Home/End 到首尾，空格播放或暂停。
6. 减少动态默认遵循系统设置，也可手动勾选；此时位置立即更新，不轮播，播放按钮用于前进一步。图形离屏或文档隐藏时暂停动画。
7. 完整输入在独立文本带中自动折行，包含全部码点及索引。空格、换行、制表符以可见符号表示；零宽成功匹配用竖线，不涂亮字符。未参与捕获组的 (-1,-1) 不是零宽成功。
8. 输出区给出真实 Python 结果表示；匹配详情面板为 JSON（null 对应 None，数组呈现 groups 元组），精确 Python repr 以输出区为准。finditer 展示迭代器展开记录；compile 案例展示编译对象调用 findall 的结果。
9. 复制代码可获得完整 Python 示例。若浏览器不允许剪贴板写入，自动选中代码供手动复制。示例打印匹配对象的字段，而不是不可稳定复用的对象地址。
10. 页眉按钮切换深浅主题。页尾包含元字符、函数和易错点速查。

内容范围
点号、锚点、量词、字符类、分支、捕获与非捕获、Unicode 字符类、原始字符串、贪婪/非贪婪、基本零宽断言；re 常见函数和 Match 常见方法；日志、日期格式重排、电话脱敏、空白清洗、简单邮箱形式校验。
日期示例仅格式重排，不校验真实日历日期；邮箱示例不是完整 RFC 或可投递性验证。电话脱敏是教学用连续数字规则，不用于生产身份或号码验证。

安全与边界
本页只选择可信、有限的教学预设，不执行任意 Python，不接收任意正则或任意文本，因此不提供在线正则执行器，也不扩展服务或引入 ReDoS 风险。
动画是匹配结果的物理化展示，不是 Python 内部回溯逐步执行。三个收集仓按捕获组存在性点亮，完整组数据永远显示在文字面板中。token 解释器只服务本页预设，不是通用正则解析器。

源码与重建（修改自己的副本后使用）
python3 source/truth.py
node source/build.mjs
python3 source/test.py
以上命令在本目录运行。需要 Python 3.10+ 和 Node，均不需要第三方库。build 会更新本实验室 index.html，不改其他实验室。iso-kit.mjs 来自本机 Anatomy 工具包的独立副本。
source/truth.json 保存 Python 3.10.21 生成的全部预设真值，包括 matches、spans、groups、flags、result 和 result_repr。
source/test.py 是不导入生成器的独立 re 复核脚本；会独立调用 re，逐一核验匹配、捕获、结果，并运行每段完整示例代码。

- 实际输入操作：下一项、上一项、键盘右键、重播、播放/暂停、主题、减少动态、token、复制按钮通过；剪贴板提示“已复制”。
