Python 列表与生成式实验室 · 使用说明
====================================

打开方式
  双击 index.html，用浏览器（Chrome / Safari / Edge）打开即可。
  完全离线，无需联网、无需安装任何东西。

页面内容
  一台等距“列表分拣台”机器：
  · 前排 9 个编号料槽 = 原列表 nums = [3, 1, 4, 1, 5, 9]
    槽前两行数字：上一行是正索引 0…，下一行是负索引 -6…-1
  · 后排料槽 = 新列表（切片、sorted()、生成式的结果落在这里）
  · 拾取滑台沿导轨移动到正在访问的槽位；滑台上的竖旗升起 = if 条件通过，落下 = 被过滤
  · 右侧 3×3 托盘 = 嵌套列表 m = [[1,2,3],[4,5,6],[7,8,9]]
    左侧滑块选行 i，前方滑块选列 j，即 m[i][j]

三个主题，共 26 个预设示例
  1. 列表（14 个）：正/负索引、切片 [start:stop:step]、索引越界 IndexError、
     切片不越界、赋值修改、append / insert / pop / remove / sort、sorted()
  2. 列表生成式（5 个）：基本变换、末尾 if 过滤、先过滤再变换、
     前置 a if c else b 条件表达式、循环变量不泄漏（NameError）
     每个示例都附有等价的 for 循环写法
  3. 嵌套列表（7 个）：m[1]、m[1][2]、m[-1][0]、展开、转置、
     [[0]*3]*3 共享同一行的陷阱 vs [[0]*3 for _ in range(3)]

操作
  · 右侧选主题、点示例
  · 点击图后：← → 切换示例，Home / End 跳到首/尾，空格或回车重播
  · “重播”“暂停巡览”按钮；右上角切换浅色 / 深色模式
  · 无人操作时会自动巡览所有示例
  · 系统开启“减少动态效果”时，直接显示最终状态，不播放动画

说明
  · 所有结果都由真实 Python 3.10.21 预先运行得出，内置在页面中；
    浏览器并不执行任意 Python 代码。
  · 每个示例都从初始的 nums 或 m 重新开始运行。

文件夹结构
  index.html      成品（单文件，所有资源已内联）
  source/         源码
    truth.py        用真实 Python 运行全部示例，生成 truth.json
    build.mjs       用 Anatomy kit 生成等距 SVG 并打包 index.html
    live.js         交互与动画
    template.html / style.css
    test.mjs        内容测试：动画终态必须与 Python 结果一致
    browser-tests.json  浏览器交互测试脚本
  验证/           验证截图（浅色、深色、手机、4 倍细节、线端检查）

重新构建（需要 Node.js 和 Python 3）
  cd source
  python3 truth.py
  node build.mjs
  node test.mjs
