Python 流程控制实验室 · 使用说明
================================

打开方式
  双击 index.html，用浏览器（Chrome / Safari / Edge）打开即可。
  完全离线，无需联网、无需安装任何东西。

页面内容
  一台等距“流程控制读码台”机器：
  · 十块代码行板按行号排列；缩进越深的行，字块越靠右，
    当前要执行的那一行会抬起并高亮
  · 左侧读码滑台移到正在执行的行；滑台上的竖旗
    升起 = 条件成立，落下 = 条件不成立
  · 每行右端有插孔，一根跳线从当前行连到“下一步要执行的行”：
    贴近的线是顺序执行，中间的线是向下跳过分支，
    绕到最外侧的线是循环回跳
  · 右上三个寄存器显示变量的值，右下纸带显示 print 的输出

四个主题，共 25 个预设程序
  1. 条件判断（7 个）：if/else、if/elif/else、条件顺序、多个独立 if、
     and/or、真值判断（空列表为假）、条件表达式
  2. 循环（6 个）：for 遍历、range()、while、累加到上限、
     嵌套循环、enumerate
  3. 跳转（7 个）：break、continue、for…else（未被打断 / 被打断）、
     while True + break、break 只跳出一层、pass
  4. 综合（5 个）：match/case、try/except、找质数、
     猜数字（预设输入）、统计及格人数

操作
  · 右侧选主题、点程序；“上一步 / 播放 / 下一步 / 重播”按钮
  · 点击图后：← → 单步，空格 播放/暂停，Home 回到开头，
    End 跳到结束，PageDown / PageUp 切换程序
  · 每一步都会说明：条件的值、走了哪个分支、取出了哪个元素、
    break / continue 跳到哪里
  · 右上角切换浅色 / 深色模式；“自动巡览”会在运行结束后切换下一个程序
  · 系统开启“减少动态效果”时，直接显示运行结束的状态，可用按钮单步

说明
  · 每个程序都在真实 Python 3.10.21 中用 sys.settrace 逐行跟踪，
    记录每一步的行号、变量、输出和条件结果，内置在页面中；
    浏览器并不执行任意 Python 代码。
  · “一步”指 Python 报告的一次行事件。循环结束时，Python 会
    再报告一次 for / while 那一行（发现没有元素或条件为假），
    所以页面上也会再停一次。

文件夹结构
  index.html      成品（单文件，所有资源已内联）
  source/         源码
    truth.py        逐行跟踪全部程序，生成 truth.json
    build.mjs       用 Anatomy kit 生成等距 SVG 并打包 index.html
    live.js         交互、跳线绘制与动画
    template.html / style.css
    test.py         独立复核：重新跟踪每个程序，逐步比对
    browser-tests.json  浏览器交互测试脚本
  验证/           验证截图（浅色、深色、手机、4 倍细节、线端检查）

重新构建（需要 Node.js 和 Python 3.10 以上）
  cd source
  python3 truth.py
  node build.mjs
  python3 test.py
