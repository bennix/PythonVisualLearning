    01 / 条件
    缩进决定谁属于谁
    if、elif、else 后面要加冒号，下面缩进的代码块属于这个分支。Python 用缩进（通常 4 个空格）表示代码块，缩进不一致会报错。
    if / elif / else 从上往下判断，只执行第一个成立的分支。0、''、[]、None 当作假。and、or、not 组合条件。
    

    02 / 循环
    for 遍历，while 看条件
    for x in 可迭代对象 依次取出每个元素，取完自动结束；range(a, b) 不包含 b。while 条件 每轮先判断，条件为假才停，循环体里一定要有让条件变化的语句，否则会死循环。
    嵌套循环中，外层每走一次，内层都从头完整走一遍。
    

    03 / 跳转
    break、continue、else
    break 立即结束所在的那一层循环；continue 跳过本次剩下的语句，进入下一轮；pass 什么也不做，只是占位。
    循环的 else 块只在循环没有被 break 打断时执行。match / case（3.10+）按顺序匹配，try / except 在出错时跳到处理代码。
