Python 文件读写实验室 · 使用说明
================================

打开方式
  双击 index.html，用浏览器（Chrome / Safari / Edge）打开即可。
  完全离线，无需联网、无需安装任何东西。
  页面只是演示，不会读写你电脑上的任何文件。

页面内容
  一台等距“文件读写台”机器：
  · 左侧代码行板按行号排列，读码滑台指向刚执行的那一行，
    跳线连到下一步；出错时竖旗落下
  · 右上 = 写缓冲托盘：write() 写入的内容先堆在这里，
    高亮块越高，还没写到磁盘的字节越多；close() / 离开 with 后清空
  · 右下 = 磁盘板：逐行显示文件在磁盘上的真实内容（· 表示空格），
    标题给出文件名和字节数
  · 磁盘板左边的光标滑块 = 读取位置 tell() 落在哪一行；
    没有打开的读取文件时，滑块变暗
  · 每一步显示的是“这一行执行之后”的状态

三个主题，共 23 个预设程序
  1. 文本文件（10 个）：with open 写入、read()、for 逐行读取、
     readline 与读写位置（seek）、readlines、'w' 会清空原文件、
     'a' 追加、不用 with 时必须 close、文件不存在、编码不一致会出错
  2. CSV（6 个）：csv.writer、csv.reader（数字读出来是字符串）、
     DictReader、DictWriter、含逗号的值自动加引号、计算平均分
  3. JSON（7 个）：json.dump、json.load、dumps / loads、
     ensure_ascii 与中文、读取 → 修改 → 写回、格式错误（单引号）、
     集合不能写成 JSON

操作
  · 右侧选主题、点程序；“上一步 / 播放 / 下一步 / 重播”按钮
  · 点击图后：← → 单步，空格 播放/暂停，Home 回到开头，
    End 跳到结束，PageDown / PageUp 切换程序
  · 右侧面板同时显示：文件对象（模式、位置、缓冲字节数）、
    磁盘上每个文件的完整内容、其他变量和 print 输出
  · 右上角切换浅色 / 深色模式；“自动巡览”会在运行结束后切换下一个程序
  · 系统开启“减少动态效果”时，直接显示运行结束的状态，可用按钮单步

说明
  · 每个程序都在真实 Python 3.10.21 中、一个全新的临时文件夹里逐行运行，
    记录每行执行后磁盘上的真实字节、文件对象的模式和读取位置，
    内置在页面中；浏览器并不执行任意 Python 代码。
  · 缓冲区里的字节数 = 交给 write() 的字节数 − 已经到达磁盘的字节数。
    记录时用了一个只增加计数、行为与内置 open 相同的文件对象；
    测试会再用真正的内置 open() 重新运行一遍，核对结果完全一致。
  · 中文在 UTF-8 中每个字占 3 个字节，所以字节数会比字符数多。

文件夹结构
  index.html      成品（单文件，所有资源已内联）
  source/         源码
    truth.py        在临时文件夹里逐行运行全部程序，生成 truth.json
    build.mjs       用 Anatomy kit 生成等距 SVG 并打包 index.html
    live.js         交互、缓冲区、磁盘与光标绘制、动画
    template.html / style.css
    test.py         独立复核：用真正的 open() 重新运行并比对磁盘内容
    browser-tests.json  浏览器交互测试脚本
  验证/           验证截图（浅色、深色、手机、4 倍细节、线端检查）

重新构建（需要 Node.js 和 Python 3.10 以上）
  cd source
  python3 truth.py
  node build.mjs
  python3 test.py
