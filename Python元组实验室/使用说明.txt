Python 元组实验室 · 使用说明
============================

打开方式
  双击 index.html，用浏览器（Chrome / Safari / Edge）打开即可。
  完全离线，无需联网、无需安装任何东西。

页面内容
  一台等距“元组封装台”机器：
  · 前排编号料槽 = 元组 t = (3, 1, 4, 1, 5)
    压在上面的横杆 + 挂锁 = “不可变”的封条
    槽前两行数字：上一行是正索引，下一行是负索引
  · 后排料槽没有封条 = 可以修改的列表（list() 转换的结果放在这里）
  · 拾取滑台沿导轨移到正在访问的槽位
    滑台上的竖旗落下、封条变亮 = 操作被拒绝（TypeError 等）
  · 右侧托盘 = 嵌套元组 n = ((1, 2), (3, 4), (5, 6))
    每一行是一个内层元组，各有自己的封条；
    左侧滑块选行 i，前方滑块选列 j，即 n[i][j]

三个主题，共 30 个预设示例
  1. 元组（12 个）：索引、负索引、切片、count / index、
     赋值报 TypeError、没有 append、+ 生成新元组、解包与 *rest、
     (5) 不是元组而 (5,) 是、逗号才是创建元组的关键
  2. 嵌套元组（9 个）：n[1]、n[1][0]、n[-1][-1]、展开、内层也不可变、
     元组里的列表可以改内容但不能换对象、元组作字典键、含列表时不可哈希
  3. 元组 ⇄ 列表（9 个）：list(t)、tuple(lst)、“先转列表再改再转回”、
     sorted() 总是返回列表、tuple('abc')、tuple(range(4))、
     嵌套结构逐层转换、list(n) 只转最外层

操作
  · 右侧选主题、点示例
  · 点击图后：← → 切换示例，Home / End 跳到首/尾，空格或回车重播
  · “重播”“暂停巡览”按钮；右上角切换浅色 / 深色模式
  · 无人操作时会自动巡览所有示例
  · 系统开启“减少动态效果”时，直接显示最终状态，不播放动画

说明
  · 所有结果都由真实 Python 3.10.21 预先运行得出，内置在页面中；
    浏览器并不执行任意 Python 代码。
  · 每个示例都在独立环境中、从代码区第一行的初始数据开始运行。

文件夹结构
  index.html      成品（单文件，所有资源已内联）
  source/         源码
    truth.py        用真实 Python 运行全部示例，并编排每一步动画
    build.mjs       用 Anatomy kit 生成等距 SVG 并打包 index.html
    live.js         交互、封条绘制与动画
    template.html / style.css
    test.mjs        内容测试：动画终态必须与 Python 结果一致
    browser-tests.json  浏览器交互测试脚本
  验证/           验证截图（浅色、深色、手机、4 倍细节、线端检查）

重新构建（需要 Node.js 和 Python 3）
  cd source
  python3 truth.py
  node build.mjs
  node test.mjs
