FIELD NOTES

把规则带走

01 / 命名

合法，不等于推荐

标识符可用 Unicode 字母、下划线和符合规则的后续字符；不能以数字开头，不能含空格或连字符，也不能是硬关键字。

score 与 Score 是不同名字。PEP 8 建议变量用 snake_case，这是风格建议，不是语法限制。

02 / 名字空间

给内置名留个位子

list = 3 在语法上合法，却遮蔽了内置 list()。match、case、type 等软关键字只在特定语法位置有特殊意义，并非一律禁用。

Python 按 NFKC 规范化标识符；例如 K 与 K 会指向同一个名字。尽量使用清晰、不易混淆的拼写。

03 / 类型

检查对象，不检查标签

type(x) 返回类型对象，type(x).__name__ 返回类型名称字符串。判断是否属于某类及其子类，通常用 isinstance(x, T)。

type(True) is int 是 False，但 isinstance(True, int) 是 True，因为 bool 是 int 的子类。
